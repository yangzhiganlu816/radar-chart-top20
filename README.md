# 雷达图 Top20 通用模板

一个**单文件、零依赖、可离线运行**的多维评价榜单可视化模板。用雷达图对比 20 个条目在 6 个维度上的表现，支持逐项播放、分数编辑、成就自定义和 BEST 转场。

打开 `index.html` 就能用 —— 不需要构建、不需要服务器、不发任何网络请求。

![效果预览](preview.png)

## 特性

- **单文件**：HTML + CSS + JS 全在一个文件里，双击即用
- **零依赖**：无框架、无 CDN、无外部请求，断网也能跑
- **数据可编辑**：分数、成就文案都能在页面上直接改，存在 localStorage
- **图片可填充**：支持批量加载本地文件夹，按文件名自动匹配条目
- **图片性能优化**：base64 转 blob URL、`img.decode()` 预解码、LRU 缓存、空闲时段预取，切换条目不卡顿
- **主题色自动分配**：按顺序取色，相邻条目颜色始终可辨识，新增条目不会撞色
- **BEST 转场**：某条目在任一维度登顶时触发专属过场动画

## 快速开始

```
直接双击 index.html
```

或者用任意静态服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 改成你自己的榜单

### 1. 改数据

搜索 `singersRawOrder`，直接编辑数组：

```js
const singersRawOrder = [
    {
        name: "项目一",                    // 条目名称
        points: [8, 7, 8.5, 9, 9, 5.5],   // 6 个维度的分数
        honors: ["🏆 成就一", "🎤 成就二", "💿 成就三", "📈 成就四"],
        duration: 10000                   // 总览时间轴上占的时长（毫秒）
    },
    // ... 增删条目直接增删这一行
];
```

**增删条目**：直接增删行即可。配色、默认成就文案都会按顺序自动分配，不用改别的地方。

**改维度名**：搜索 `dimNames`，顺序要和 `points` 一一对应：

```js
const dimNames = ["全年热度","爆曲战绩","体量与商务","专业荣誉","现场实力","原创能力"];
```

**改维度权重**：搜索 `rankingWeightPercent`，总和需为 100：

```js
const rankingWeightPercent = [25, 20, 20, 13, 10, 12];
```

**改配色**：搜索 `themePalette`，按顺序取色，条目数超过调色板长度会循环：

```js
const themePalette = ["#F3A6C8", "#7C3AED", /* ... */];
```

### 2. 配图

页面内的「照片」面板提供两种方式：

- **批量加载本地文件夹**：一次性选中多张图，文件名去掉扩展名后与条目名精确匹配（也兼容去空格后的模糊匹配）。比如 `项目一.jpg` 会自动配给「项目一」。
- **单个填入**：在面板里选条目，再选一张图。

配好的图存在浏览器 localStorage，刷新不丢。

> 图片只存在本地浏览器，不会上传到任何服务器。

### 3. 分数与成就编辑

- 分数：编辑面板里直接改六个维度的数值，回车生效
- 成就：每条有三组可编辑文案（综合荣誉 / 代表作 / 数据亮点）
- BEST 标记：某维度分数等于全场最高值时自动标记，无需手动设置
- 恢复默认：面板里的「恢复默认照片」和重置按钮

## 浏览器兼容

需要支持 `requestIdleCallback`（Chrome / Edge / Safari / Firefox  recent 版本）。代码里有降级分支，不支持时自动回退到 `setTimeout`。

用到 ES2020+ 语法（可选链、空值合并）和 Canvas 2D。

## 可选增强：人脸定位

模板**不含**人脸识别功能，也不联网加载任何模型。如果你想让上传的人像自动对齐到画面特定位置：

1. 自行引入 face-api.js 之类的库
2. 重写 `getFacePosition(image)`，返回 `{ x, y }`（百分比坐标）：

```js
async function getFacePosition(image) {
    // 返回 null 表示不做人脸对齐，调用方会回落到默认对齐方式
    return { x: 50, y: 42 };
}
```

## 已知设计取舍

**排序用整数加权，显示用分段线性映射。** 排序唯一依据是 `weightedScoreUnits()`（整数累计，避免浮点误差和先四舍五入导致的误排序）。显示总分走三段线性映射（锚点 7.83 / 8.5 / 10.485），这段映射**绝不参与排序**，所以名次和并列关系不随显示口径变化。

**BEST 按实际生效的分数重算，并列最高全部标记**，且在读取用户编辑缓存之后才算。
